# Step 6：增量模式——新增或修改接口

**触发场景：** 已生成过接口文档，新增接口或修改已有接口定义。

## 阶段 6-1：理解变更需求

读取 `WORK_DIR/接口文档.md`、`WORK_DIR/RountMap.md`。若用户未描述需求，询问：

```
请描述变更需求（新增接口/修改参数/修改响应/调整 URL 等）：
```

## 阶段 6-2：分析影响，展示变更清单，等待确认

```
=== 变更清单确认 ===
【新增接口】
  • [Method] [URL]：[说明] | 幂等：[✅/❌]

【修改接口】
  • [Method] [URL]：[变更说明（如新增 xxx 参数/修改 yyy 字段类型）]

【影响分析】
  • [如有相关接口需同步调整，在此说明]

回复"确认"生成 / "调整"修改意见
```

## 阶段 6-3：生成变更文档

Read `SKILL_DIR/steps/api-spec.md` 和 `SKILL_DIR/steps/api-doc-format.md`，按规范生成。

**使用 `Edit` 工具补丁式更新 `接口文档.md`：**
- 新增接口 → 在对应模块章节末尾追加完整接口章节
- 修改接口 → 精确修改对应接口的参数表格或示例行
- 删除接口 → 删除对应接口章节，更新文件头接口总数

## 阶段 6-4：输出报告

```
✅ 变更完成：新增 N 个接口，修改 M 个接口
已更新：[WORK_DIR]/接口文档.md
```
