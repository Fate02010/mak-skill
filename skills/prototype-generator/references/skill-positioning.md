# Skill Positioning

## Best-Fit Use Cases

Use `prototype-generator` when the user wants to turn product materials into structured prototype deliverables:

- Generate HTML prototypes from PRD,需求文档,资料文件夹
- Generate draw.io wireframes from product materials
- Add pages or modules to an existing prototype
- Produce requirements + page specs + prototype as one workflow

## Strong Signals

Typical user phrases:

- “生成原型”
- “根据资料做原型”
- “生成 HTML 原型图”
- “生成 draw.io / drawio”
- “做线框图”
- “补一个页面原型”
- “新增 XX 模块的原型”

## Out of Scope

Do not use this skill by default for:

- Pure visual polish or aesthetic exploration
- Generic UI inspiration without product materials
- Single marketing image / poster / banner requests
- Non-prototyping engineering work

## Workflow Outcome

The expected outcome is not just “a page”.
The expected outcome is a gated prototype pipeline:

`materials -> requirements -> task list -> page specs -> render -> validate -> final prototype`
