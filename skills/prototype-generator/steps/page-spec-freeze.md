# 页面规格冻结契约

本文件定义 `.prototype-generator/page_specs/page_spec_*.md` 的统一职责与最小格式。

## 目的

页面规格冻结是渲染前的唯一结构化输入。
一旦进入渲染阶段，禁止再回读原始资料或自由发挥补页面。

## 输出位置

- 统一目录：`WORK_DIR/.prototype-generator/page_specs/`
- 文件命名：`page_spec_[模块英文名].md`
- `WORK_DIR` 根目录出现新的 `page_spec_*.md` 视为流程错误

## 冻结要求

每个页面必须冻结以下信息：

- 页面名称
- 页面类型
- 输出文件名或最终页面标识
- 关键字段
- 列表列
- 关键操作
- 跳转关系
- 状态枚举

禁止只写“页面说明”或“设计思路”而不写结构化字段。

## 推荐格式

```md
# 页面规格冻结

## 模块信息
- 模块名称：后台-用户管理
- 模块英文名：user
- 输出格式：html

## 页面规格：用户列表
### 页面元信息
- 页面类型：web_list
- 输出文件：user-list.html
- 是否导航页：否

### 字段
| 字段名 | 控件/展示 | 必填 | 说明 |
| --- | --- | --- | --- |
| 用户名 | input | 否 | 支持模糊搜索 |
| 手机号 | input | 否 | 手机号格式 |
| 状态 | select | 否 | 启用/停用 |

### 列表列
| 列名 | 说明 |
| --- | --- |
| 用户名 | 显示真实用户名 |
| 手机号 | 显示脱敏手机号 |
| 状态 | Tag 展示 |
| 创建时间 | 默认倒序 |

### 操作
- 新增用户
- 编辑用户
- 删除用户
- 查看详情

### 跳转
- 新增用户 -> 用户表单
- 编辑用户 -> 用户表单
- 删除用户 -> 删除确认弹窗
- 查看详情 -> 用户详情

### 状态
- 启用
- 停用
- 待审核
```

## 渲染门禁

- HTML：先冻结 `page_spec`，再从 `page_spec` 渲染 HTML 页面
- draw.io：先输出 `page_model`，再由 `build_page_spec.py` 生成 `page_spec`
- 任一格式只要 `page_spec` 缺页、缺字段、缺跳转，就不得进入最终交付
