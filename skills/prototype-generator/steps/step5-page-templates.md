# 页面骨架模板库

规格化 Agent 生成 page_spec 时，**必须先按页面类型选择对应骨架模板**，将模板中的固定元素直接复制到 page_spec 中，然后在 `{{业务字段区}}` 标记处填入从需求文档提取的实际字段行。

---

## 使用规则

1. **先识别页面类型**（列表页 / 表单页 / 详情页 / 登录注册页 / Dashboard）
2. **复制对应骨架模板**的所有行到 page_spec
3. **在标记处插入业务字段**，id 从模板最大 id 之后递增
4. **禁止删除模板中的固定元素**（导航栏、背景、分页、提交/取消按钮等）
5. **禁止修改固定元素的坐标**，只修改 value 列（填入真实页面标题、按钮文案等）
6. 若页面不完全匹配某类型，选最接近的骨架，再增删个别行
7. **移动端主导航页（底部 Tab Bar 页面）必须使用含 bottom_bar 行的模板**（模板二或模板九）；内页（详情、表单、登录等）不得加 bottom_bar
