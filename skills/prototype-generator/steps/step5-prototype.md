# Step 5：工作流——并行生成 HTML 原型图

这是核心步骤，分五个阶段执行。

## 阶段 5-1：读取需求，功能划分

1. 读取 `详细需求文档.md` 中的"原型图清单"
2. 将所有需要生成的页面按功能模块分组
3. 估算每个页面的复杂度（简单/中等/复杂）
4. **绘制页面跳转地图**：梳理所有页面之间的跳转关系，确保每条用户操作路径都有对应的目标页面。如果发现某条流程缺少承接页面（例如点击"提交"后无结果页），立即补充到任务清单中。
5. 输出功能划分结果到 `原型任务清单.md`

## 阶段 5-2：拆分生成任务

将原型页面拆分为独立的生成任务，每个任务包含：
- 页面名称和文件名
- 所需参考的需求内容（从需求文档中截取相关段落）
- **完整的进出跳转关系**：该页面从哪些页面跳入、点击哪些元素跳转到哪些页面（用文件名指定）
- 视觉风格要求

将任务清单写入 `原型任务清单.md`：

```markdown
# 原型图生成任务清单

## 页面跳转地图
[用箭头描述完整的页面流转，确保无断头路]
登录页 → 首页 → 详情页 → 确认页 → 成功页
首页 → 个人中心页
...

## 任务列表
- [ ] 任务1：[页面名称] → 输出文件：prototypes/[文件名].html
      进入来源：[来源页面]  跳出去向：[目标页面及触发元素]
- [ ] 任务2：[页面名称] → 输出文件：prototypes/[文件名].html
      进入来源：[来源页面]  跳出去向：[目标页面及触发元素]
...

## 共用配置
- 设计风格：[从产品资料中提炼的设计风格]
- 主色调：[颜色]
- 过渡动效：[页面切换方式，如 slide/fade/push]
```

## 阶段 5-3：并行生成 HTML 原型图

**重要：** 使用 `Agent` 工具启动多个并行子任务，每个子任务负责生成一个或一组相关页面。

每个子任务的提示词必须包含：
1. 需求内容（从需求文档截取相关段落）
2. 跳转关系（本页面的进出跳转）
3. 指示子任务先 Read `steps/html-spec.md` 获取 HTML 规范
4. 设计风格和主色调

**子任务提示词模板：**

```
先读取 [skill目录]/steps/html-spec.md 获取 HTML 原型规范，然后根据以下需求生成 [页面名称] 的 HTML 原型图。

【需求内容】
[相关需求内容]

【跳转关系】
- 本页面从 [来源页面.html] 跳入
- [按钮/操作A] → 跳转到 [目标页面A.html]
- [按钮/操作B] → 跳转到 [目标页面B.html]
- [返回/取消] → 跳转到 [来源页面.html]

【设计风格】[风格]，主色调：[颜色]

【需求变更记录要求】
在生成过程中，如果发现以下情况，必须在文件末尾追加 HTML 注释记录：
- 需求文档中描述不清晰，做了假设性决策
- 发现需求遗漏（某个流程缺少承接页面或状态）
- 为实现功能闭环主动新增了需求文档中未提及的页面或交互

注释格式：
<!-- REQUIREMENT_CHANGES
[变更类型: 假设/遗漏/新增]
页面: [当前页面名]
描述: [具体变更内容]
建议更新需求文档: [应在需求文档哪个章节如何更新]
-->

保存到：prototypes/[文件名].html
```

**并行策略：**
- 简单页面：每个 Agent 生成 2-3 个页面
- 复杂页面：每个 Agent 只生成 1 个页面
- 最多同时启动 5 个并行 Agent

## 阶段 5-4：收集需求变更，更新需求文档

所有并行任务完成后，**在生成导航首页之前**，执行以下操作：

1. 读取所有生成的 HTML 文件，提取其中的 `<!-- REQUIREMENT_CHANGES ... -->` 注释
2. 汇总所有变更记录，判断哪些需要同步回需求文档：
   - **假设性决策**：如果假设合理，更新需求文档将其固化为正式需求
   - **需求遗漏**：补充到需求文档对应章节（功能点、流程、原型图清单等）
   - **主动新增**：在需求文档原型图清单中补充新增页面
3. 直接编辑 `详细需求文档.md`，将变更同步进去（在文档末尾追加"变更记录"章节，说明本次更新内容和原因）
4. 将汇总的变更内容记录到 `原型任务清单.md` 末尾的"需求变更汇总"区块

## 阶段 5-5：生成导航首页

所有子任务完成、需求文档更新后，生成 `prototypes/index.html`：
- 列出所有已生成的原型页面，附一句功能说明
- 提供直接跳转链接
- 显示产品名称和版本信息
- 以可视化方式展示页面跳转地图（用简单的箭头连线 HTML 表示）
