> **用途：** 集中定义系统中所有枚举类型字段的合法取值，供原型 subagent 生成 Tag 颜色、下拉选项和状态流转时直接引用，避免各功能点各自描述不一致。

> 1. **列表页**（含筛选、表格、分页、操作列"编辑/删除"、右上角"新增"按钮）

> 3. **编辑表单页或编辑弹窗**（可与新增合并为"新增/编辑"共用）

> **质量标准：**
> - 每个功能点必须填写**页面字段规格**（列表列定义 + 筛选条件 + 分页规则，或 表单字段 + 校验规则 + 业务规则），这是原型图字段精准度的直接依据
> - 列表页：筛选条件逐个列出（含控件类型和枚举值）；表格列逐列列出（含排序、操作列说明）；分页规则写明默认条数和排序字段
> - 表单页：每个字段一行，列出控件类型、是否必填、校验规则（长度/格式/唯一性等）、占位提示
> - 详情页：明确展示字段列表、状态流转和各状态下可操作的按钮
> - **页面类型**：必须从以下选项中选择一个——列表页 / 表单页（独立页面）/ 表单页（弹窗）/ 详情页 / 独立页面 / 首页/Dashboard / 确认弹窗 / 其他
> - **是否主导航页**：移动端 App/小程序中出现在底部 Tab Bar 上的页面填「是」，其余填「否」；Web 后台填「否」
> - **主要字段数量**：列表页填「N列」，表单/详情页填「N字段」，弹窗填「-」；供原型 Agent 评估复杂度和分配生成任务
> - 竞品参考应指明本产品的改进方向而非照抄
> - 文档应足够详细，让原型 subagent 无需猜测字段名和校验规则即可直接绘制
