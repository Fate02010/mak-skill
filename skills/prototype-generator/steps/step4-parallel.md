# 大型需求文档并行分块编写流程

> 触发条件：模块数 > 4 或功能点 > 20 时加载本文件。

## 步骤一：任务拆分

将所有模块分组，每组 2-4 个模块：
- 分块文件：`需求文档_模块A_模块B.md`、`需求文档_模块C_模块D.md` ...
- 通用章节：`需求文档_通用.md`（含产品概述、用户角色、核心业务流程、数据模型、非功能需求）

## 步骤二：并行生成各分块

- **Claude Code**：使用 `Agent` 工具在单次响应中同时启动所有写作 Agent
- **Codex**：使用 `Task` 工具并设置 `run_in_background=true`，用 `TaskOutput` 收集结果

每个 Agent / Task 提示词模板：

```
编写以下模块的需求文档章节，保存为 [WORK_DIR/分块文件名]。

【写作范围】仅写"## 3. 功能模块清单"的对应部分：
- 模块X：[功能点列表]
- 模块Y：[功能点列表]

【竞品参考】Read [WORK_DIR/竞品分析报告.md] 中 [模块X/Y 相关章节] 获取竞品洞察。

【格式】严格遵循 step4-doc-format.md 中功能模块清单的结构。

完成后输出：✅ [分块文件名] 完成，N 个模块，M 个功能点。
```

## 步骤三：合并为最终文档

```
1. 读取 需求文档_通用.md → 写入文档头部（第1-2章、第4-7章）
2. 按模块顺序依次读取各分块文件 → 拼接为完整的第3章
3. 删除所有临时分块文件（需求文档_*.md）
4. 输出：✅ 合并完成，详细需求文档.md 共 N 模块，M 功能点，约 X 行
```
