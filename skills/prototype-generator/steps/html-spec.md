# HTML 原型图规范

生成的每个 HTML 原型图必须符合以下规范。

## 技术规范
- 纯 HTML + CSS + 原生 JS（不依赖外部库，除非用 CDN 引入 TailwindCSS）
- 可选择使用 TailwindCSS CDN：`<script src="https://cdn.tailwindcss.com"></script>`
- 响应式设计，支持手机和桌面

## 内容规范
- **真实数据：** 使用符合业务场景的示例数据，不用"Lorem ipsum"或"示例文字"
- **完整界面：** 包含导航栏、主要内容区、必要的操作按钮
- **交互反馈：** 按钮 hover 效果、表单验证提示、加载状态等
- **状态展示：** 如果页面有多种状态（空状态/有数据/加载中），至少展示最常见的状态

## 视觉规范
- 使用卡片式布局
- 合理的间距和字体大小
- 颜色使用产品主色调
- 图标使用 Unicode 符号或 emoji 代替（不依赖图标库）

## 交互与动效要求（必须实现）
- 所有页面跳转用 `<a href="相对路径">` 或 JS `location.href` 实现，确保可以真实点击跳转
- 页面进入时有淡入动效（CSS: opacity 0→1，duration 300ms）
- 按钮点击有缩放反馈（transform: scale(0.97)，duration 100ms）
- 表单提交、删除等操作有加载态（按钮文字变"处理中..."，禁用重复点击）
- 如果有列表滑动操作，实现 swipe 手势效果（JS touch event）
- 弹窗/抽屉用动效展开（translateY / scale，duration 200ms）

## 功能闭环要求（必须实现）
- 本页面内所有按钮和链接都必须有明确去向，不允许出现点击无反应的死按钮
- 如果目标页面尚未生成，用 `alert("跳转到[目标功能]")` 临时占位，但不能留空
- 表单提交后必须有反馈（成功提示 / 错误提示），不能提交后无反应
- 列表的空状态必须有对应的空态界面和引导操作
