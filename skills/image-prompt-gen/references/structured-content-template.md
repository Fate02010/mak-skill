# 结构化内容模板

将分析结果转化为信息图布局可直接使用的结构化内容，为 Step 5 提示词生成做准备。

## 核心原则

| 原则 | 要求 |
|------|------|
| **忠实原文** | 不添加、不改写、不合并未在原文出现的信息 |
| **标签精简** | 每个文字标签 ≤ 4 汉字 / 3 英文词 |
| **视觉优先** | 每个章节都要指定对应视觉元素（图标/图形/数字） |
| **数据原句** | 所有统计数字和引语保持原文格式 |

## 输出格式

保存到 `structured-content.md`：

```markdown
# [信息图标题]（≤ 8 个汉字）

## 副标题
[≤ 15 字的补充说明]

## 布局结构
- 布局类型：[layout]
- 总版块数：[N]
- 视觉重心：[哪个版块是主视觉]

---

## 版块 1：[版块标题，≤ 4 汉字]

**核心标签**：[显示在图中的文字，≤ 4 汉字]
**副标签**：[次级说明，≤ 8 汉字]
**数据亮点**：[如有数字，原文原句]
**视觉元素**：[图标描述，如"文档堆叠图标"、"人物轮廓"、"齿轮图形"]
**颜色建议**：[如"蓝色系"、"暖橙色"]

---

## 版块 2：[版块标题]
...（每个版块重复以上结构）

---

## 全局文字标签清单

> 以下是将出现在图中的所有文字，按 AI 图片生成可用格式整理：

- 主标题：[文字]
- 版块标题（依次）：[文字1]、[文字2]、[文字3]...
- 数据值（依次）：[值1]、[值2]...
- 底部备注：[如有]
```

## 不同布局的版块数建议

| 布局 | 建议版块数 | 说明 |
|------|----------|------|
| `linear-flow` | 3-6 | 步骤数量 |
| `timeline` | 4-8 | 时间节点数 |
| `comparison` | 2 | 两侧对比项 |
| `pyramid` | 3-5 | 层级数 |
| `hub-spoke` | 1 中心 + 4-8 辐射 | 辐射点数量 |
| `funnel` | 3-5 | 漏斗层级 |
| `circular-flow` | 4-6 | 循环节点 |
| `bento-grid` | 4-9 | 格子数量 |
| `dashboard` | 3-8 | 指标数量 |
| `magazine` | 1 主 + 2-3 辅 | 版块结构 |
