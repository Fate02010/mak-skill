# dashboard — 数据看板

展示多个数据指标、KPI 或统计数据，仪表盘风格。

## 结构

- 顶部 1-3 个大数字核心指标
- 中部图表区（可有柱状图/折线/环形图）
- 底部补充指标行
- 整体深色或专业商务配色

## 最适合

- 数据报告摘要
- KPI 展示
- 业务指标看板
- 数据对比分析

## Image Prompt 空间描述语言

```
A data dashboard infographic on [深色/白色] background. At the top: N large metric cards in a row, each showing a giant bold number "[数值]" with a small label below and a trend arrow indicator. In the middle: [图表类型] chart visualizing [数据关系]. At the bottom: a row of smaller supporting metric cards. Clean grid layout, bold typography, [配色] color palette. Professional analytics dashboard aesthetic.
```

## 指标结构（提示词写法）

```
Top hero metrics (large bold numbers):
- Metric 1: giant number "[值]", label "[指标名]", trend arrow up/down
- Metric 2: giant number "[值]", label "[指标名]", trend arrow up/down
- Metric 3: giant number "[值]", label "[指标名]"

Middle chart: [bar chart / line chart / donut chart] showing [数据描述]
[图表数据描述]

Bottom supporting metrics:
- "[指标名]: [值]"
- "[指标名]: [值]"
```
