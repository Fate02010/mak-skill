# circular-flow — 循环流程

展示循环往复的过程，如生命周期、迭代循环、持续改进。

## 结构

- 圆形排列的 4-6 个节点
- 弧形箭头连接各节点表示顺序
- 中央可有核心标签
- 节点有图标+标签

## 最适合

- 迭代开发循环（如 DevOps、Scrum）
- 产品生命周期
- 自然循环（水循环、季节）
- 持续改进流程（PDCA）

## Image Prompt 空间描述语言

```
A circular flow diagram on white background. N rounded rectangle or circular nodes arranged in a perfect circle, evenly spaced. Curved arrows between each pair of adjacent nodes indicate clockwise flow direction. Each node contains: a small icon above and a bold 2-word label below. The center of the circle contains a large bold label "[核心主题]" in a lightly tinted circle. Nodes alternate between [颜色1] and [颜色2].
```

## 节点结构（提示词写法）

```
Center label: "[循环核心主题]"
Nodes arranged clockwise starting from top:
- Node 1 (top, [颜色]): icon of [图标], label "[节点名]"
- Node 2 (right, [颜色]): icon of [图标], label "[节点名]"
- Node 3 (bottom, [颜色]): icon of [图标], label "[节点名]"
- Node 4 (left, [颜色]): icon of [图标], label "[节点名]"
Curved arrows connecting each node clockwise.
```
