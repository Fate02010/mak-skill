# magazine — 杂志封面

单主题视觉叙事，像杂志封面或文章配图，主视觉 + 少量文字。

## 结构

- 大面积主视觉（场景/人物/产品）占据主要区域
- 顶部或底部有标题文字区
- 2-3 个辅助信息点
- 视觉冲击力强，文字简洁

## 最适合

- 文章封面图
- 话题概念图
- 产品发布视觉
- 品牌故事图

## Image Prompt 空间描述语言

```
A magazine-cover style infographic illustration in [AR] format. The majority of the image is occupied by a large dramatic [主视觉描述]. In the [top/bottom] section: a bold large title "[标题]" in [颜色] text on a [对比色] background strip. A small subtitle "[副标题]" below the main title. [2-3个关键词/数字] displayed as floating text badges or labels overlaid on the image.
```

## 内容结构（提示词写法）

```
Main visual (large, occupies 70% of image): [主视觉的详细描述，如"a developer at an illuminated workstation surrounded by floating code panels"]
Text overlay elements:
- Large title at [top/bottom]: "[主标题，≤6汉字]"
- Subtitle: "[副标题，≤10汉字]"
- Key badge 1: "[关键词或数字]"
- Key badge 2: "[关键词或数字]"
```

## 推荐配对风格

- `cinematic-photo`：电影感封面
- `concept-art`：科幻/技术主题
- `flat-vector`：现代简约封面
