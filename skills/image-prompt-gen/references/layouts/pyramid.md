# pyramid — 层级金字塔

用三角形层级展示优先级、重要性或从属关系。

## 结构

- 顶部到底部逐层变宽（或倒置）
- 3-5 层，每层一个标签和描述
- 层级越高代表越重要/越稀少
- 可有图例说明各层含义

## 最适合

- 需求优先级（马斯洛式）
- 能力/技能等级
- 组织架构
- 技术栈层级

## Image Prompt 空间描述语言

```
A pyramid hierarchy infographic on white background. A large centered triangle divided into N horizontal tiers from top to bottom. Top tier (smallest): [颜色] with bold label "[顶层标题]" and small subtitle. Middle tier(s): [颜色] with bold label and subtitle. Bottom tier (largest): [颜色] with bold label and subtitle. Each tier has a distinct color gradient from top (darkest) to bottom (lightest) or vice versa. Small icons on the left or inside each tier.
```

## 层级结构（提示词写法）

```
Pyramid tiers from top to bottom:
- Top tier (smallest, [颜色]): icon of [图标], bold label "[层级名]", subtitle "[≤6词说明]"
- Middle tier ([颜色]): icon of [图标], bold label "[层级名]", subtitle "[≤6词说明]"
- Bottom tier (largest, [颜色]): icon of [图标], bold label "[层级名]", subtitle "[≤6词说明]"
```
