# hub-spoke — 中心辐射

中心节点向外辐射多个相关节点，展示一个核心概念与多个关联元素的关系。

## 结构

- 中央大圆/图标代表核心概念
- 4-8 个辐射节点环绕排列
- 连线从中心延伸到各节点
- 各节点有图标+标签

## 最适合

- 核心概念的多个应用场景
- 一个产品/技术的多个特性
- 影响因素分析
- 生态系统展示

## Image Prompt 空间描述语言

```
A hub-and-spoke diagram on white background. A large central circle in the middle of the image contains a prominent icon and bold label "[核心概念]". N smaller circular nodes arranged evenly around the center in a ring, each connected to the center by a straight line or curved path. Each satellite node contains: a small icon and a 2-word label below. The central hub is [主色], satellite nodes are [辅色].
```

## 节点结构（提示词写法）

```
Central hub: large [颜色] circle, icon of [图标], bold label "[核心名称]"
Satellite nodes arranged clockwise from top:
- Node 1: [颜色] circle, icon of [图标], label "[节点名]"
- Node 2: [颜色] circle, icon of [图标], label "[节点名]"
...（N个节点）
```
