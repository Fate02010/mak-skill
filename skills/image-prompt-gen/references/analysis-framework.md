# 信息图内容分析框架

分析源内容，为布局×风格推荐和结构化提炼做准备。

## 分析目标

在生成信息图提示词之前，深度分析源材料：
- 理解内容的本质结构
- 识别最佳视觉化路径
- 提取所有数据点（原文原句）
- 匹配最优布局×风格

## 内容类型分类

| 类型 | 特征 | 推荐布局 | 推荐风格 |
|------|------|---------|---------|
| **流程/教程** | 有序步骤、操作指南、how-to | `linear-flow` | `flat-vector`, `digital-illustration` |
| **时间线/历史** | 时间顺序、演变、里程碑 | `timeline` | `flat-vector`, `watercolor` |
| **对比分析** | A vs B、优缺点、方案比较 | `comparison` | `flat-vector` |
| **层级结构** | 优先级、分类体系、金字塔 | `pyramid` | `flat-vector`, `concept-art` |
| **关系网络** | 核心概念辐射、影响关系 | `hub-spoke` | `flat-vector`, `digital-illustration` |
| **转化漏斗** | 递进缩减、筛选过程 | `funnel` | `flat-vector` |
| **循环过程** | 迭代周期、生命周期、闭环 | `circular-flow` | `flat-vector` |
| **多主题总览** | 并列特性、功能集合、摘要 | `bento-grid` | `flat-vector` |
| **数据指标** | 统计数字、KPI、数据报告 | `dashboard` | `flat-vector` |
| **视觉叙事** | 单主题深度、封面故事 | `magazine` | `cinematic-photo`, `concept-art` |

## 复杂度评估

| 级别 | 信息点数量 | 布局建议 |
|------|----------|---------|
| **简单** | 3-5 个核心点 | 单焦点布局（`hub-spoke`, `funnel`） |
| **中等** | 5-8 个核心点 | 分段布局（`linear-flow`, `comparison`, `pyramid`） |
| **复杂** | 8+ 个核心点 | 密集布局（`bento-grid`, `dashboard`, `timeline`） |

## 文字标签提炼原则（关键！）

AI 图片生成模型文字渲染能力有限，标签越短越准确：

| 元素类型 | 字数限制 | 示例 |
|----------|---------|------|
| 主标题 | ≤ 8 个汉字 / 5 个英文词 | "AI 全流程开发工作流" |
| 步骤/节标题 | ≤ 4 个汉字 / 3 个英文词 | "产品设计" / "Spec Coding" |
| 数据标签 | 纯数字 + 单位 | "36%" / "25K lines" |
| 副标题 | ≤ 8 个汉字 / 6 个英文词 | "AI 担任 PM + 设计师 + 工程师" |

**绝对禁止**：在标签中使用完整句子，如"通过规格化编码提升开发效率"→改为"规格化编码"

## 数据提取规则

所有统计数字和引语必须**原文原句**保留：
- ✅ "研发提效 36%" （原文）
- ❌ "效率提升三成" （改写）
- ✅ "2.5 万行代码"（原文）
- ❌ "大量代码"（模糊化）
