# landscape-photo — 风光摄影

广袤的自然和城市风光，强调光影与空间感。

## 核心关键词

```
landscape photography, wide angle, dramatic sky, long exposure, panoramic view
```

## 光照关键词

| 场景 | 关键词 |
|------|--------|
| 黄金时刻 | `golden hour, warm amber light, long shadows` |
| 蓝调时刻 | `blue hour, twilight, cool tones` |
| 暴风雪 | `stormy sky, dramatic clouds, moody lighting` |
| 星空 | `starry night, Milky Way, long exposure, dark sky` |
| 晨雾 | `morning mist, fog rolling over mountains, soft diffused light` |

## 相机/镜头建议

- `wide angle lens 16mm` — 宏大感
- `shot on Nikon D850, 14-24mm f/2.8` — 专业感
- `drone photography, aerial view` — 俯瞰视角

## 完整提示词示例

```
a vast mountain valley at golden hour, dramatic peaks in the background, autumn foliage in orange and red, a winding river reflecting the sky, warm amber light casting long shadows, wide angle landscape photography, shot on Nikon D850 14-24mm, ultra-detailed, 8K resolution
```

## 适合主题

山水、海洋、城市天际线、建筑外观、四季变换
