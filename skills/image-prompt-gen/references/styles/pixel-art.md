# pixel-art — 像素艺术

复古 8-bit / 16-bit 游戏美学，每个像素都有意义。

## 核心关键词

```
pixel art, 8-bit, retro game style, pixelated, sprite art, low resolution aesthetic
```

## 风格变体

| 风格 | 关键词 |
|------|--------|
| 经典 8-bit | `NES style, 8-bit pixel art, limited color palette` |
| 16-bit 精细 | `SNES style, 16-bit pixel art, RPG game sprite` |
| 等距像素 | `isometric pixel art, detailed scene, pixel city` |
| 像素动画帧 | `pixel animation frame, GIF-style, sprite sheet` |

## 技术特征

- `visible square pixels` — 可见像素块
- `limited color palette, 16-32 colors` — 有限色板
- `dithering technique` — 抖动技法
- `no anti-aliasing` — 无抗锯齿
- `1x1 pixel clarity` — 每像素分明

## 完整提示词示例

```
a cozy pixel art coffee shop interior, warm orange and brown color palette, pixel art style, 16-bit SNES aesthetic, detailed furniture and bookshelves, a barista character behind the counter, isometric perspective, soft pixel glow from lamps, highly detailed scene
```

## 适合主题

复古游戏场景、角色头像、数字收藏品（NFT）、科技/怀旧主题
