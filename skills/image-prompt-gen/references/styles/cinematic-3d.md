# cinematic-3d — 电影级 3D 渲染

电影品质的 CGI，写实材质，戏剧光影，高规格视觉呈现。

## 核心关键词

```
cinematic 3D render, CGI, photorealistic, Unreal Engine 5, ray tracing, subsurface scattering
```

## 风格变体

| 风格 | 关键词 |
|------|--------|
| 写实产品 | `product visualization, 3D render, studio lighting, photorealistic material` |
| 角色模型 | `3D character render, high poly, ZBrush sculpt, detailed texture` |
| 环境场景 | `architectural visualization, interior render, global illumination` |
| 奇幻世界 | `fantasy 3D environment, Unreal Engine 5, epic scale, volumetric fog` |

## 技术特征

- `global illumination` — 全局光照
- `volumetric lighting and fog` — 体积光与雾
- `ray-traced reflections` — 光线追踪反射
- `subsurface scattering on skin` — 皮肤次表面散射
- `PBR materials` — 物理材质
- `octane render / Redshift render` — 渲染器参考

## 完整提示词示例

```
a futuristic sports car on a wet night street, cinematic 3D render, Unreal Engine 5, ray-traced reflections on the car body, neon lights reflected in puddles, volumetric fog, photorealistic materials, dramatic side lighting, ultra-detailed, 8K resolution
```

产品可视化、建筑效果图、游戏角色、科幻场景
