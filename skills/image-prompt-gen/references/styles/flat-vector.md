# flat-vector — 扁平矢量插画

简洁色块、无阴影或轻微阴影、现代设计感，适合品牌和 UI。

## 核心关键词

```
flat vector illustration, minimal design, clean shapes, vibrant solid colors, no shadow
```

## 风格变体

| 风格 | 关键词 |
|------|--------|
| Material Design | `Google Material Design style, elevation shadows, bold colors` |
| 企业插画 | `corporate illustration style, friendly characters, geometric` |
| 图标风格 | `icon design, minimal flat icons, unified line weight` |
| 渐变扁平 | `flat design with gradient fills, modern color gradient` |

## 技术特征

- `clean geometric shapes` — 几何图形
- `limited color palette, 3-5 colors` — 克制配色
- `consistent line weight if outlined` — 统一线重
- `negative space usage` — 巧用空白
- `scalable vector style` — 可缩放矢量风

## 完整提示词示例

```
a female character sitting at a laptop working from home, flat vector illustration, clean geometric shapes, vibrant color palette of teal and coral, minimal design, slight drop shadow for depth, white background, friendly and professional, modern corporate illustration style
```
