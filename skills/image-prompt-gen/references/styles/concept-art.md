# concept-art — 概念艺术

专业游戏/电影概念艺术，黑暗精细，史诗感强。

## 核心关键词

```
concept art, digital painting, professional concept design, detailed environment, AAA game art
```

## 风格变体

| 风格 | 关键词 |
|------|--------|
| 奇幻世界 | `fantasy concept art, epic scene, detailed architecture, magical elements` |
| 科幻未来 | `sci-fi concept art, futuristic design, industrial details, mech` |
| 黑暗奇幻 | `dark fantasy, gothic atmosphere, moody lighting, intricate details` |
| 英雄角色 | `hero character concept, full armor, dynamic pose, character design` |
| 世界构建 | `world-building art, environment design, sprawling landscape` |

## 技术特征

- `dynamic lighting, dramatic shadows` — 戏剧光影
- `intricate architectural details` — 精细建筑细节
- `atmospheric perspective` — 空气透视
- `concept art by [artist], artstation trending` — 艺术家参考
- `cinematic composition` — 电影构图
