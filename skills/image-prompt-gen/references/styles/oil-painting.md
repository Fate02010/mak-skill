# oil-painting — 油画

经典西方油画风格，厚重质感，色彩丰富，具有时间沉淀感。

## 核心关键词

```
oil painting, canvas texture, impasto, classical painting, rich colors, painterly
```

## 风格变体

| 风格 | 关键词 |
|------|--------|
| 古典写实 | `classical realism, old master style, Rembrandt lighting, chiaroscuro` |
| 浪漫主义 | `romantic oil painting, dramatic atmosphere, Delacroix style` |
| 现代油画 | `contemporary oil painting, expressive brushstrokes, mixed media` |
| 厚涂派 | `impasto technique, thick paint, visible brushstrokes, textured surface` |

## 技术特征

- `visible brushstrokes` — 可见笔触
- `canvas texture` — 画布纹理
- `chiaroscuro lighting` — 强烈明暗对比
- `glazing technique` — 透明叠色
- `warm color palette, earthy tones` — 暖色调、大地色

## 完整提示词示例

```
a still life with antique books, a candle, and dried roses on a wooden table, classical oil painting, old master style, Rembrandt lighting, dramatic chiaroscuro, warm amber tones, thick impasto brushstrokes, canvas texture, museum quality
```

## 适合主题

人物肖像、静物、历史场景、自然风光
