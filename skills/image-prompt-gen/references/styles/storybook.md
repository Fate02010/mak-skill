# storybook — 绘本插画

温暖可爱的绘本风格，亲切感十足，适合儿童内容和温情故事。

## 核心关键词

```
children's book illustration, storybook art, warm and cozy, friendly characters, picture book style
```

## 风格变体

| 风格 | 关键词 |
|------|--------|
| 经典绘本 | `classic picture book illustration, Eric Carle style, bold shapes` |
| 温馨水彩 | `soft watercolor children's book, gentle colors, warm light` |
| 现代可爱 | `modern children's illustration, cute rounded shapes, pastel colors` |
| 立体质感 | `3D render, soft toy aesthetic, children's animation style` |

## 技术特征

- `rounded soft shapes` — 圆润造型
- `warm pastel color palette` — 温暖马卡龙色调
- `friendly, non-threatening characters` — 亲切无威胁感的角色
- `simple clean backgrounds` — 简洁背景
- `whimsical details` — 奇幻细节

## 完整提示词示例

```
a small fox cub sitting under a giant mushroom in a magical forest, surrounded by fireflies and tiny flowers, children's book illustration, soft watercolor style, warm golden light filtering through the trees, rounded cute shapes, pastel color palette, whimsical and cozy atmosphere, storybook art
```

## 适合主题

儿童读物、亲子内容、品牌吉祥物、节日贺卡、治愈系插画
