# impressionism — 印象派

松散笔触，光影变幻，户外自然光，色彩鲜活。

## 核心关键词

```
impressionist painting, loose brushstrokes, dappled light, vibrant colors, Monet style
```

## 代表艺术家参考

| 艺术家 | 特点 | 关键词 |
|--------|------|--------|
| 莫奈（Monet） | 水面光影、花园 | `Claude Monet style, water lilies, garden scene` |
| 雷诺阿（Renoir） | 人物温柔、暖光 | `Pierre-Auguste Renoir style, warm light, figures` |
| 毕沙罗（Pissarro） | 乡村风景 | `Camille Pissarro style, countryside` |
| 德加（Degas） | 动态人物 | `Edgar Degas style, dancers, movement` |

## 技术特征

- `broken color technique` — 色块并列技法
- `dappled sunlight through leaves` — 树叶间斑驳光影
- `soft edges, blended forms` — 柔和边缘
- `en plein air, outdoor natural light` — 户外自然光写生
- `complementary color contrasts` — 互补色对比

## 完整提示词示例

```
a woman sitting in a sunlit garden, surrounded by blooming flowers, impressionist painting style, loose expressive brushstrokes, dappled light through tree canopy, vibrant complementary colors, Monet inspired, soft edges, warm summer atmosphere
```

## 适合主题

花园、水景、乡村、人物活动场景
