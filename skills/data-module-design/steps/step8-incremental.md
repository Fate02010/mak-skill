# Step 8：增量模式——新增或修改 SQL

**触发场景：** 已有 SQL 文件，新增表或修改表结构，无需重跑完整流程。

## 阶段 8-1：理解变更需求

读取 `WORK_DIR/[产品名称].sql`、`WORK_DIR/领域模型.md`、`WORK_DIR/RountMap.md`。

若用户未提供变更描述，询问：

```
请描述变更需求（新增表/新增字段/修改索引等）：
```

## 阶段 8-2：分析影响，展示变更清单

分析变更影响（字段/关系/索引/破坏性变更/领域模型），展示后**等待确认**：

```
=== 变更清单确认 ===
【新增表】• t_[表名]（[说明]）：[核心字段] | 索引：[关键索引]
【修改表】• t_[表名].[字段名]：[变更说明]
【关联影响】• t_[现有表] 需新增 [字段] 支持关联
【领域模型影响】• [如有，说明] ← 确认后同步更新 领域模型.md
⚠️ 破坏性变更：• [字段类型缩短/删除字段等]
回复"确认"生成 / "调整"修改
```

## 阶段 8-3：生成变更 SQL

Read `SKILL_DIR/steps/step4-sql-rules.md`，生成：

- **新增表**：完整建表语句（规范同全量模式）
- **修改表**（ALTER，不同数据库语法参照 `step1-db-select.md`）：

```sql
ALTER TABLE `t_[表名]` ADD COLUMN `[字段]` [类型] COMMENT '[注释]' AFTER `[参考字段]`;
ALTER TABLE `t_[表名]` MODIFY COLUMN `[字段]` [新类型] COMMENT '[注释]';
ALTER TABLE `t_[表名]` ADD INDEX `idx_[字段]` (`[字段]`);
ALTER TABLE `t_[表名]` DROP INDEX `idx_[字段]`;
ALTER TABLE `t_[表名]` DROP COLUMN `[字段]`;  -- ⚠️ 破坏性
```

## 阶段 8-4：追加到主文件

```sql
-- ============================================================
-- 变更记录：[日期] [变更摘要]
-- ============================================================
[SQL 内容]
```

## 阶段 8-5：同步更新相关文档

**如影响领域模型**（新聚合/新实体/关系变更）：更新 `领域模型.md`，变更记录追加 `| v[X+1] | [摘要] | 增量变更 [日期] |`

**如新增表或关系/索引变更**：
- 更新 `ER关系图.md`（Mermaid 图、关系汇总表、索引表）
- 更新 `数据详细设计文档.md`：为新增表追加字段章节，修改已变更表的字段行，更新数据字典和变更记录

## 阶段 8-6：输出报告

```
✅ 变更完成：新增 N 张表，修改 M 张表
追加到：[WORK_DIR]/[产品名称].sql
领域模型：[已更新 vX.X / 无影响]
ER 关系图：[已更新 / 无影响]
详细设计文档：[已更新 / 无影响]
⚠️ 破坏性变更：[如有]
```
