# Step 8：增量模式——新增或修改 SQL

**触发场景：** 已生成过 SQL 文件，用户希望新增表或修改现有表结构，无需重跑完整流程。

---

## 阶段 8-1：理解变更需求

1. 读取 `WORK_DIR/[产品名称].sql` 了解现有表结构
2. 读取 `WORK_DIR/领域模型.md` 了解当前领域模型（如存在）
3. 读取 `WORK_DIR/RountMap.md` 了解产品背景
4. 请用户描述变更内容（若已提供则跳过）：

```
=== 请描述变更需求 ===

支持以下两类操作：

【新增】新增表/模块
  示例："新增消息通知模块，包含通知记录表和用户通知关联表"

【修改】修改现有表
  示例："订单表新增支付方式字段"、"用户表的 email 字段改为唯一索引"

请描述你的需求：
```

## 阶段 8-2：分析变更影响，输出变更清单

根据用户描述，结合现有表结构分析变更影响：

**新增表时：**
- 识别新表的字段、关系、索引
- 检查是否需要在现有表上新增外键/关联字段
- 检查是否需要新增中间表
- 评估是否影响领域模型（新聚合/新实体）

**修改表时：**
- 确认字段变更类型（新增/修改类型/修改约束/删除）
- 确认索引变更（新增/删除/修改）
- 评估对现有数据的影响（是否有破坏性变更）
- 评估是否影响领域模型（实体关系变更）

向用户展示变更清单，**等待确认后继续**：

```
=== 变更清单确认 ===

【新增表】
  • [表名]（[说明]）：[核心字段] | 索引：[关键索引]
  • [中间表名] ⚡中间表

【修改表】
  • [表名].[字段名]：[变更说明]

【关联影响】
  • [现有表名] 需新增字段 [xxx] 以支持关联

【领域模型影响】
  • [如变更影响领域模型，在此说明] ← 确认后将同步更新 领域模型.md

⚠️ 破坏性变更（需谨慎）：
  • [如有字段类型缩短、删除字段等，在此提示]

请确认：
- 回复"确认"：生成变更 SQL
- 回复"调整"：说明修改意见
```

## 阶段 8-3：生成变更 SQL

用户确认后，Read `SKILL_DIR/steps/step4-sql-rules.md` 遵循 SQL 规范，生成两类 SQL：

### 新增表

直接生成完整建表语句（与全量模式相同规范）。

### 修改表（ALTER 语句）

```sql
-- 新增字段
ALTER TABLE `[表名]`
  ADD COLUMN `[字段名]` [类型] [约束] COMMENT '[注释]' AFTER `[参考字段]`;

-- 修改字段
ALTER TABLE `[表名]`
  MODIFY COLUMN `[字段名]` [新类型] [新约束] COMMENT '[注释]';

-- 新增索引
ALTER TABLE `[表名]`
  ADD INDEX `idx_[字段名]` (`[字段名]`);

-- 删除索引
ALTER TABLE `[表名]`
  DROP INDEX `idx_[字段名]`;

-- 删除字段（⚠️ 破坏性，需用户已确认）
ALTER TABLE `[表名]`
  DROP COLUMN `[字段名]`;
```

> 不同数据库的 ALTER 语法差异，参照 `SKILL_DIR/steps/step1-db-select.md` 中的语法差异表。

## 阶段 8-4：追加到主 SQL 文件

变更 SQL 生成完毕后，追加到 `WORK_DIR/[产品名称].sql` 文件末尾：

```sql
-- ============================================================
-- 变更记录：[日期] [变更摘要]
-- ============================================================

[新增建表语句 / ALTER 语句]
```

## 阶段 8-5：更新领域模型（如有影响）

**如果变更影响到领域模型（新增实体、修改关系、新增聚合等），必须更新 `WORK_DIR/领域模型.md`：**

1. 在对应聚合中新增/修改实体条目
2. 更新实体关系总览
3. 在变更记录中追加：

```markdown
| v[X+1] | [变更内容摘要] | 增量模式变更，[日期] |
```

更新完成后告知用户：`领域模型.md 已同步更新（vX.X）`

## 阶段 8-6：输出变更报告

```
✅ 变更 SQL 生成完成

新增表：N 张
修改表：M 张（ALTER 语句 X 条）
已追加到：[WORK_DIR]/[产品名称].sql
领域模型：[已更新 vX.X / 未影响，无需更新]

⚠️ 破坏性变更提示（如有）：
[字段删除/类型缩短等需人工确认的操作]
```
