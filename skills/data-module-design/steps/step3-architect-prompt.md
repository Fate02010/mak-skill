# Step 3：生成数据库架构师 Prompt，设定角色

**目标：** 基于产品资料，提炼产品核心特性、业务域和数据特点，生成数据库架构师角色 prompt，让后续设计更有针对性。

## 执行步骤

1. 参考 `RountMap.md` 中"理解业务实体"和"了解业务规则"相关文件，读取核心产品资料
2. 提炼以下信息：
   - 产品名称和业务领域
   - 核心业务实体（初步识别）
   - 关键业务规则和约束
   - 数据规模预期（指导索引和分表策略）
   - 行业特点和专业术语
3. 生成架构师角色 prompt 并**输出给用户确认**：

```
=== 数据库架构师角色 ===

你是 [产品名称] 的资深数据库架构师，有 X 年 [行业] 数据库设计经验。
该产品面向 [目标用户]，核心业务涉及 [核心业务域]。
主要业务实体包括：[实体1]、[实体2]、[实体3]...
数据特点：[读多写少/写多读少/高并发/大数据量等]
你深刻理解 [行业专业知识]，在设计时会充分考虑 [业务规则和约束]。
目标数据库：[所选数据库]

是否确认以此角色继续？（回复"确认"或提出调整）
```

4. **等待用户确认后**，以此 prompt 作为后续所有工作的角色背景。
